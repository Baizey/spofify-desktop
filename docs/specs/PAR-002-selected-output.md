# PAR-002 — Control the already selected output

**Status:** specified, unassigned. **Prerequisites:** none; 001/003 shared dock edits are coordination, not dependencies. Follow [delivery guide](README.md).

## Useful delivery / existing seams

The desktop can play a search result on, and control, an already-selected browser output while remaining silent locally. One bottom player shows authoritative remote metadata/transport/progress, not the last locally clicked row. Preserve the existing guarded local single-track path. G references: `internal/web/{playback.go,playback_dto.go}`, `static/playback-sync.js`; D `player.rs::View/Device/consume/reconcile`, `engine.rs::tick/publish`, `api.rs::player/player_view`, bottom UI/main callbacks.

## Contract

- Auth-scoped actor registers once after successful sign-in for controller participation; registration is not selection/audio permission. Retain one known session-bound ID in memory, serialize register/poll, dispose known ID once on logout/normal shutdown. Lost registration acceptance is uncertain, never immediate blind re-register spam or name-based dedup/delete. Recovery is explicit and bounded; no durable IDs/names/credentials. Picker rendering later has no lifecycle side effects.
- `GET /api/me/player` is observation only. `POST` actions `register{name}`, `poll{deviceId,epoch,acks?,stateSeq?,state?}`, `command{deviceId,epoch,commandId,command}`, `leave{deviceId}` retain exact session/Origin/CSRF. Parse bounded full device names/availability, active vs selected transfer, epoch, lease/quarantine/stateAge, full v1 musical state and command outcomes. Widen endpoint-specific envelopes for legitimate state+directives (Go request cap 2 MiB, queue 1,000); choose/document a measured finite response bound, not a blanket global increase. Parsing a full snapshot is not permission for the restricted local receiver to accept it.
- Existing search Play routes `play(track,context?)` to active output; remote Pause/Resume/Next/Previous/seek (seconds) use one bounded operation path, truthful terminal `ok/blocked/media/rejected/timeout/cancelled`, not HTTP-200 optimism. Coalesce unsent seeks, never replay accepted/uncertain commands. Remote queue display is observation, not local output authority. Local output path retains sample/session/lease fences and no remote-volume API.
- Genuinely unselected explicit Play preserves guarded self admission and matching terminal activation before music. Never take over a selected unavailable remote or use ordinary Play as explicit transfer. Connection retry/reconnect never replays music.
- Project elapsed using bounded state age and monotonic interpolation only while playing/not waiting. Distinguish switching, quarantine, loading, unavailable, blocked/media and unknown outcome; remote errors direct retry to actual output. 404 retires registration safely; 409 observes without retry; auth loss fences. Stall deadlines must not outlive independent lease/sample safety.
- Correct wire distinction before routing controls: incoming `clear` retains current/history and removes only upcoming; incoming `close` cancels/stops/resets. **No Close player, Stop listening, reset-style Stop, dismiss or expand popup in the dock.** Remove MVP Stop exposure if 001 has not landed. Keep internal/incoming close and loading-interrupting Pause. No queue editor/picker or priority advertisement in this unit.

## Checks / acceptance

Unit/mock tests cover full valid remote state (duplicates/context/occurrence), malformed/oversize envelopes, observation never grants lease, session-bound issuer, actual-final-state ACK, command dedup, stale response, seek coalescing, 404/409/401/403, lost command reply, stalled poll and clear-vs-close. Retain `claim_is_only_self_unselected_and_never_forced`, lease/send-time and sample-fence regressions.

Against owned current-Go + actual browser receiver, native Play/Pause/Resume/Next/Previous/seek changes that receiver; assert **zero local media GET/output** while remotely controlling. Show remote title/time and truthful delayed/failure/retry with native interaction/screenshots, local MVP regression and guarded unselected first Play. Native receiver must still reject unsupported full prepared queues without harming a healthy source. Record actual receiver effects, not model-only success. This is a complete controller release, explicitly not full receiving or device-picker parity.
